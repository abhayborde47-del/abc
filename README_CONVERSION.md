# Top-level README

This branch (feature/springboot-postgresql-react) contains the start of the conversion from the original PHP project (packed in NewProject.zip) to a Java Spring Boot + PostgreSQL backend and a React + Vite frontend.

Structure:
- /backend : Spring Boot (Maven) backend
- /frontend: React + Vite frontend
- /analysis : inventory and plans

Follow the READMEs inside each folder for development instructions. I will update these files as I progress through full conversion.
