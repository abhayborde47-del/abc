# Backend README

This backend is a Spring Boot application (Java 21, Maven) that will implement the REST APIs for the converted PHP application.

Quick start (development):

1. Create a PostgreSQL database called `abcdb` and update credentials in application.yml
2. Run the app with Maven:

   mvn spring-boot:run -f backend/pom.xml

3. The app runs on http://localhost:8080

Further instructions will be added as the project conversion progresses.
